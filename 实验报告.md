## 1. 项目概述

### 1.1 项目背景

随着高校学生数量的增加，二手物品交易需求日益增长。传统的线下交易方式效率低下，信息传播范围有限。本项目旨在开发一个校园二手交易平台，为学生提供便捷、安全的二手物品交易服务。

### 1.2 项目目标

本项目的主要目标包括：

1. 提供商品展示与搜索功能
2. 实现用户注册与登录功能
3. 支持商品发布与管理
4. 实现订单管理与支付功能
5. 提供即时聊天功能

### 1.3 技术架构

本项目采用前后端分离架构：

- **前端：** Android原生应用，使用Java语言开发
- **后端：** Spring Boot框架，使用Java语言开发
- **数据库：** SQLite（移动端）+ MySQL（服务端）
- **网络通信：** OkHttp + RESTful API

### 5.1 网络请求封装

**代码清单5.1 ApiService.java**

```java
public class ApiService {
    private static final String BASE_URL = "http://10.0.2.2:8080/api/";
    private static final MediaType JSON = MediaType.get("application/json; charset=utf-8");
    
    private OkHttpClient client;
    private Gson gson;
    private static ApiService instance;

    private ApiService() {
        client = new OkHttpClient.Builder()
                .connectTimeout(15, TimeUnit.SECONDS)
                .readTimeout(15, TimeUnit.SECONDS)
                .writeTimeout(15, TimeUnit.SECONDS)
                .build();
        gson = new GsonBuilder().setDateFormat("yyyy-MM-dd HH:mm:ss").create();
    }

    public static ApiService getInstance() {
        if (instance == null) {
            synchronized (ApiService.class) {
                if (instance == null) {
                    instance = new ApiService();
                }
            }
        }
        return instance;
    }

    // GET请求
    public <T> Result<T> get(String endpoint, Class<T> clazz) {
        try {
            Request request = new Request.Builder()
                    .url(BASE_URL + endpoint)
                    .get()
                    .build();
            
            Response response = client.newCall(request).execute();
            if (response.isSuccessful() && response.body() != null) {
                String json = response.body().string();
                return gson.fromJson(json, new TypeToken<Result<T>>() {}.getType());
            }
            return Result.error("请求失败");
        } catch (Exception e) {
            return Result.error(e.getMessage());
        }
    }

    // POST请求
    public <T> Result<T> post(String endpoint, String jsonBody, Class<T> clazz) {
        try {
            RequestBody body = RequestBody.create(jsonBody, JSON);
            Request request = new Request.Builder()
                    .url(BASE_URL + endpoint)
                    .post(body)
                    .build();
            
            Response response = client.newCall(request).execute();
            if (response.isSuccessful() && response.body() != null) {
                String json = response.body().string();
                return gson.fromJson(json, new TypeToken<Result<T>>() {}.getType());
            }
            return Result.error("请求失败");
        } catch (Exception e) {
            return Result.error(e.getMessage());
        }
    }

    public Gson getGson() {
        return gson;
    }
}
```

public class MainActivity extends AppCompatActivity {
    private RecyclerView recyclerView;
    private EditText etSearch;
    private Button btnSearch;
    private ItemAdapter adapter;
    private ApiService apiService;
    private ExecutorService executorService;
    private List<Item> itemList = new ArrayList<>();
    private String currentSort = "time_desc";

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        
        // 初始化组件
        recyclerView = findViewById(R.id.recyclerView);
        etSearch = findViewById(R.id.et_search);
        btnSearch = findViewById(R.id.btn_search);
        
        apiService = ApiService.getInstance();
        executorService = Executors.newSingleThreadExecutor();
        
        // 设置RecyclerView
        adapter = new ItemAdapter();
        recyclerView.setLayoutManager(new LinearLayoutManager(this));
        recyclerView.setAdapter(adapter);
        
        // 设置搜索监听
        btnSearch.setOnClickListener(v -> searchItems(etSearch.getText().toString()));
        
        // 加载商品列表
        loadItems();
    }

    // 加载商品列表
    private void loadItems() {
        executorService.execute(() -> {
            Result<PageResult<Item>> result = apiService.get(
                "items?page=1&size=20&sort=" + currentSort, 
                new TypeToken<PageResult<Item>>() {}.getType());
            
            if (result.isSuccess() && result.getData() != null) {
                itemList = result.getData().getList();
                runOnUiThread(() -> adapter.notifyDataSetChanged());
            }
        });
    }

    // 搜索商品
    private void searchItems(String keyword) {
        executorService.execute(() -> {
            try {
                String encodedKeyword = URLEncoder.encode(keyword, "UTF-8");
                String url = "items/search?keyword=" + encodedKeyword + "&page=1&size=20&sort=" + currentSort;
                
                Result<PageResult<Item>> result = apiService.get(
                    url, new TypeToken<PageResult<Item>>() {}.getType());
                
                if (result.isSuccess() && result.getData() != null) {
                    itemList = result.getData().getList();
                    runOnUiThread(() -> adapter.notifyDataSetChanged());
                }
            } catch (UnsupportedEncodingException e) {
                e.printStackTrace();
            }
        });
    }
}

public class LoginActivity extends AppCompatActivity {
    private EditText etUsername, etPassword;
    private Button btnLogin, btnRegister;
    private ApiService apiService;
    private ExecutorService executorService;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_login);
        
        // 初始化组件
        etUsername = findViewById(R.id.et_username);
        etPassword = findViewById(R.id.et_password);
        btnLogin = findViewById(R.id.btn_login);
        btnRegister = findViewById(R.id.btn_register);
        
        apiService = ApiService.getInstance();
        executorService = Executors.newSingleThreadExecutor();
        
        // 设置监听
        btnLogin.setOnClickListener(v -> attemptLogin());
        btnRegister.setOnClickListener(v -> {
            Intent intent = new Intent(LoginActivity.this, RegisterActivity.class);
            startActivity(intent);
        });
    }

    // 尝试登录
    private void attemptLogin() {
        String username = etUsername.getText().toString().trim();
        String password = etPassword.getText().toString().trim();
        
        // 输入验证
        if (username.isEmpty() || password.isEmpty()) {
            Toast.makeText(this, "请输入用户名和密码", Toast.LENGTH_SHORT).show();
            return;
        }
        
        executorService.execute(() -> {
            String jsonBody = "{\"username\": \"" + username + "\", \"password\": \"" + password + "\"}";
            Result<User> result = apiService.post("users/login", jsonBody, User.class);
            
            runOnUiThread(() -> {
                if (result.isSuccess()) {
                    saveUser(result.getData());
                    Toast.makeText(LoginActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
                    // 跳转到首页
                    Intent intent = new Intent(LoginActivity.this, MainActivity.class);
                    intent.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);
                    startActivity(intent);
                    finish();
                } else {
                    Toast.makeText(LoginActivity.this, result.getMessage(), Toast.LENGTH_SHORT).show();
                }
            });
        });
    }

    // 保存用户信息到SharedPreferences
    private void saveUser(User user) {
        getSharedPreferences("campus_trade", MODE_PRIVATE)
                .edit()
                .putLong("user_id", user.getId())
                .putString("username", user.getUsername())
                .putString("nickname", user.getNickname())
                .apply();
    }
}

                Log.e("OrderActivity", "Load orders error: " + e.getMessage());

public class PaymentActivity extends AppCompatActivity {
    private TextView tvOrderId, tvAmount;

    private ExecutorService executorService;
    private Long orderId;
    private Double amount;

    @Override
    protected void onCreate(Bundle savedInstanceState) {

        setContentView(R.layout.activity_payment);
        
        tvOrderId = findViewById(R.id.tv_order_id);
        tvAmount = findViewById(R.id.tv_amount);
        rgPaymentMethod = findViewById(R.id.rg_payment_method);
        btnPay = findViewById(R.id.btn_pay);
        
        apiService = ApiService.getInstance();
        executorService = Executors.newSingleThreadExecutor();
        
        // 获取订单信息
        Intent intent = getIntent();
        orderId = intent.getLongExtra("order_id", 0);
        amount = intent.getDoubleExtra("amount", 0.0);
        
        // 显示订单信息
        tvOrderId.setText("OR" + System.currentTimeMillis());
        tvAmount.setText("¥" + String.format("%.2f", amount));
        
        // 设置支付按钮监听
        btnPay.setOnClickListener(v -> makePayment(getSelectedPaymentMethod()));
    }

    // 执行支付
    private void makePayment(String paymentMethod) {
        btnPay.setEnabled(false);
        btnPay.setText("支付中...");
        
        executorService.execute(() -> {
            try {
                Map<String, Object> requestBody = new HashMap<>();
                requestBody.put("orderId", orderId);
                requestBody.put("paymentMethod", paymentMethod);
                requestBody.put("amount", amount);
                
                Gson gson = new Gson();
                String jsonRequest = gson.toJson(requestBody);
                
                Result<PaymentResponse> result = apiService.post(
                    "payment/create", jsonRequest, PaymentResponse.class);
                
                runOnUiThread(() -> {
                    btnPay.setEnabled(true);
                    btnPay.setText("确认支付");
                    
                    if (result.isSuccess()) {
                        Toast.makeText(PaymentActivity.this, "支付成功!", Toast.LENGTH_SHORT).show();
                        Intent intent = new Intent(PaymentActivity.this, OrderActivity.class);
                        intent.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);
                        startActivity(intent);
                        finish();
                    } else {
                        Toast.makeText(PaymentActivity.this, 
                            "支付失败: " + result.getMessage(), Toast.LENGTH_SHORT).show();
                    }
                });
            } catch (Exception e) {
                Log.e("PaymentActivity", "支付失败", e);
                runOnUiThread(() -> {
                    btnPay.setEnabled(true);
                    btnPay.setText("确认支付");
                    Toast.makeText(PaymentActivity.this, "支付失败", Toast.LENGTH_SHORT).show();
                });
            }
        });
    }
}

## 7. 数据持久化方案

### 7.1 本地存储方案

本应用采用两种本地存储方式：

#### 7.1.1 SharedPreferences

用于存储用户会话信息，包括：

（1）用户ID  
（2）用户名  
（3）昵称  
（4）登录状态

**代码示例：**

```java
// 保存用户信息
getSharedPreferences("campus_trade", MODE_PRIVATE)
        .edit()
        .putLong("user_id", user.getId())
        .putString("username", user.getUsername())
        .apply();

// 获取用户信息
Long userId = getSharedPreferences("campus_trade", MODE_PRIVATE)
        .getLong("user_id", 0);
```

#### 7.1.2 SQLite数据库

用于存储本地缓存数据，包括：

（1）商品浏览记录  
（2）收藏商品列表  
（3）聊天消息缓存

### 7.2 服务端存储方案

服务端采用MySQL数据库，使用Spring Data JPA进行数据访问：

（1）用户数据存储  
（2）商品数据存储  
（3）订单数据存储  
（4）聊天记录存储

## 8. 代码规范

### 8.1 命名规范

#### 8.1.1 类命名

- 使用大驼峰命名法（PascalCase）  
- 类名应具有描述性，如 `MainActivity`、`ApiService`

#### 8.1.2 方法命名

- 使用小驼峰命名法（camelCase）  
- 方法名应使用动词开头，如 `loadItems()`、`createOrder()`

#### 8.1.3 变量命名

- 使用小驼峰命名法  
- 变量名应清晰描述其用途，如 `userId`、`itemList`

### 8.2 代码格式规范

（1）缩进：使用4个空格  
（2）行宽：每行不超过120字符  
（3）空行：方法之间空一行，逻辑块之间空一行  
（4）花括号：左花括号不换行，右花括号单独一行

### 8.3 注释规范

（1）类注释：说明类的功能和职责  
（2）方法注释：说明方法的功能、参数、返回值  
（3）代码注释：对复杂逻辑进行解释  
（4）TODO注释：标记待完成的功能
